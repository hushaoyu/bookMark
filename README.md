# 万事屋 - 个人工具 PWA 应用

> 一个功能丰富的个人日常工具集，支持 PWA 安装，无需下载即可在浏览器中使用的「瑞士军刀」应用。

---

## 📖 项目介绍

**万事屋** 是一款基于 **React + TypeScript** 构建的 **PWA（Progressive Web App）** 应用，集成了个人日常所需的多种工具模块。得益于 PWA 特性，应用可以直接安装到设备主屏幕，支持离线使用，提供接近原生应用的使用体验。

所有数据均存储在浏览器本地，无需注册账号，保护个人隐私安全。

---

## ✨ 功能总览

应用提供 **8 大功能模块**，覆盖日常记账、理财、记录、待办等多种场景：

| 模块 | 图标 | 说明 |
|------|------|------|
| 📒 记账本 | 💰 | 收支记录、预算管理、统计分析 |
| 👶 宝宝记录 | 👶 | 成长记录、里程碑追踪、身高体重 |
| 📊 定期理财 | 📊 | 定期存款/理财产品的收益管理 |
| 💸 活期理财 | 💸 | 活期/货币基金类理财收益追踪 |
| 📋 欠账记录 | 📋 | 借贷往来记录与管理 |
| 🔗 链接管理 | 🔗 | 常用链接收藏与分类管理 |
| 📝 待办清单 | 📝 | 日常待办事项管理 |

### 1. 📒 记账本

完整的个人收支管理工具，帮助您掌握财务动向。

- **收支记录**：按类别记录收入和支出，支持自定义分类
- **预算管理**：设定月度/年度预算，实时监控预算使用情况
- **统计分析**：按月/年维度查看收支统计，直观的数据可视化
- **日历视图**：以日历形式查看每日收支明细
- **账单分摊**：支持 AA 制账单分摊功能
- **数字键盘**：专用数字键盘，快速录入金额
- **数据持久化**：支持 IndexedDB 存储，数据安全可靠
- **搜索筛选**：按日期、分类、描述等条件搜索记录
- **数据导入导出**：支持 JSON 格式的数据备份与迁移

### 2. 👶 宝宝记录

新手爸妈必备的宝宝成长记录工具。

- **宝宝档案**：记录宝宝的姓名、性别、出生日期等基本信息
- **里程碑追踪**：满月、百天、周岁等重要里程碑自动计算与记录
- **身高体重记录**：定期记录宝宝的身高体重，跟踪成长曲线
- **生肖信息**：根据出生日期自动显示生肖信息
- **多人记录**：支持同时记录多个宝宝的数据
- **自定义里程碑**：支持自定义添加特殊纪念日

### 3. 📊 定期理财

定期存款和理财产品收益管理。

- **产品登记**：记录理财产品的名称、类型、金额、利率等信息
- **收益计算**：自动计算到期收益和收益率
- **状态跟踪**：追踪产品状态（持有中/已到期/已赎回）
- **多人管理**：支持按持有人分类管理（本人/配偶等）
- **银行标注**：记录所属银行或平台信息

### 4. 💸 活期理财

活期存款及货币基金类理财的收益追踪。

- **每日收益**：记录每日收益变动，追踪收益趋势
- **七日年化**：记录七日年化收益率变动
- **快捷记录**：快速更新当日收益金额
- **银行管理**：按银行或平台分类管理

### 5. 📋 欠账记录

清晰管理个人借贷往来。

- **借贷分类**：区分借出和借入两种类型
- **对方管理**：记录借贷对象信息
- **金额追踪**：清晰记录每笔借贷的金额和日期
- **状态管理**：标记已还/未还状态，记录还款日期
- **关联描述**：添加借贷原因和备注信息

### 6. 🔗 链接管理

收藏和管理常用链接。

- **链接收藏**：保存网页链接，支持标题、URL 和标签
- **标签系统**：为链接添加标签，便于分类管理
- **搜索功能**：按关键词搜索已保存的链接
- **多维度排序**：支持按标题、URL、标签数量排序
- **批量操作**：支持多选、全选、批量删除
- **数据导入导出**：支持 JSON 格式的备份与迁移
- **覆盖/合并导入**：导入时支持覆盖或合并两种模式

### 7. 📝 待办清单

简洁高效的待办事项管理。

- **任务创建**：快速添加待办事项
- **截止日期**：为任务设置截止日期
- **完成标记**：勾选标记任务完成状态
- **分类目标**：支持任务目标分类

## 🛡️ 安全特性

- **应用锁保护**：支持设置应用密码，保护隐私
- **生物识别**：支持 WebAuthn 生物识别认证（指纹/面部识别）
- **模块二次验证**：进入各功能模块时可单独开启密码验证
- **灵活认证策略**：支持密码优先、生物识别优先或双重认证
- **数据加密存储**：敏感数据加密后存储在浏览器本地
- **无服务器架构**：所有数据仅保存在本地，无需注册账号

## 📱 PWA 特性

| 特性 | 说明 |
|------|------|
| 📥 **可安装** | 支持安装到设备主屏幕，像原生应用一样使用 |
| 🚀 **离线使用** | 通过 Service Worker 缓存资源，无网络也可使用 |
| 📐 **响应式设计** | 完美适配桌面端、平板和手机端 |
| 🔄 **自动更新** | 自动检测应用更新，一键更新到最新版本 |
| 💾 **持久化存储** | 申请浏览器持久化存储权限，防止数据被清除 |
| 🎨 **独立窗口** | 安装后以独立窗口运行，无浏览器地址栏 |

## 🏗️ 技术栈

| 技术 | 用途 |
|------|------|
| **React 18** | UI 框架 |
| **TypeScript** | 类型安全 |
| **Vite** | 构建工具，极速热更新 |
| **React Context API** | 状态管理 |
| **CSS Modules** | 样式隔离 |
| **IndexedDB** | 数据持久化存储 |
| **Service Worker** | 离线缓存与 PWA 支持 |
| **Web App Manifest** | PWA 安装配置 |
| **Web Speech API** | 浏览器 TTS 语音合成 |
| **WebAuthn API** | 生物识别认证 |
| **Web Crypto API** | 密码哈希与数据加密 |
| **代码分割 (lazy)** | 按需加载，优化首屏性能 |

## 📦 数据导入导出

应用支持完整数据的 **导入** 与 **导出** 功能，方便数据备份和在不同设备间迁移：

- **导出**：一键导出所有数据为 JSON 文件
- **导入**：支持 JSON 文件导入
  - **覆盖模式**：清空现有数据后导入
  - **合并模式**：与现有数据合并，自动去重
- 支持的数据类型：记账记录、预算、链接、定期理财、活期理财、欠账记录、宝宝记录
